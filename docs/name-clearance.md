This is a practical pre-publication collision screen, not a legal opinion or trademark
clearance. It records what was checked on 2026-08-27 so the decision can be reproduced.

graphics. The planned identifiers are:

- GitHub repository: `itsryanlenk/lenkraster`
- Python distribution and import package: `lenkraster`
- commands: `lenkraster` and `lenkraster-mcp`
- local MCP server name: `lenkraster`
